# Step English Coach Level Standards

This document defines the internal difficulty standard for original English exam preparation content. The product must not copy official past papers, but questions should follow public level descriptions, topic ranges, task formats, and expected language difficulty.

## Grade 4 Level

- 水平：日本中学中级程度。
- 重点：基础日常词汇、学校生活、家庭、购物、旅行、天气、方向、兴趣、简单公告和邮件阅读。
- 语法范围：简单句、一般现在时、一般过去时、未来表达 will / be going to、can / must / have to、比较级、There is / There are、疑问词、不定词基础、动名词基础。
- 阅读：短句、短会话、公告、简单邮件、短故事。句子长度要短，但不能低龄化。
- 写作：4级一次试验不强制作文。本产品可提供基础造句和短句输出练习，但不作为模拟考试正式 section。
- 难度控制：不要只出现 apple / dog / cat 这类幼儿词。词汇应接近日本初中中级，例如 borrow, return, practice, arrive, ticket, library, weather, interesting, careful, popular。
- 解释：中文解释要适合初中生，指出关键词、语法结构或上下文线索。

## Grade 3 Level

- 水平：日本中学毕业程度。
- 重点：现在完成、被动语态、关系代词基础、不定词、动名词、简单观点表达、邮件/短文阅读。
- 语法范围：现在完成 since / for / experience、被动语态、关系代词 who / which / that、不定词进阶、动名词进阶、too ... to、so ... that、ask 人 to do、make 人 形容词、because / although / if。
- 阅读：公告、邮件、身近日常短文、学校活动、国际交流、兴趣和志愿活动。需要有信息定位和简单推理。
- 写作：包含 E-mail 回复和 Opinion Composition。目标是能用 25-35 词表达观点和理由。
- 难度控制：题目要体现中学毕业水平，不应只考单词意思；应加入语境、时态、从句和短文理解。
- 解释：帮助学生理解为什么错，尤其说明时态、语序、连接词、被动或关系代词的选择理由。

## Pre-2 Level

- 水平：高中中级程度。
- 重点：更复杂的阅读、社会生活话题、学校、环境、科技、健康、社区、工作体验、意见表达。
- 语法范围：分词、关系代名词进阶、关系副词基础、仮定法基础、比较表达进阶、间接疑问句、完了形进阶、被动语态进阶、however / therefore / while 等连接词、长句阅读中的修饰关系。
- 阅读：较长邮件、说明文、社会生活短文、环境和科技主题。应包含主旨、细节、因果和简单推论。
- 写作：E-mail 回复和 Opinion Essay，难度高于3级。目标 50-60 词，要求观点、理由、例子、连接词。
- 难度控制：明显比3级难。应使用高中基础到中级词汇，例如 opportunity, responsibility, environment, community, advantage, reduce, increase, communicate, volunteer, technology。
- 解释：中文解释要指出上下文线索、逻辑关系和语法结构，帮助学生建立可迁移的解题方法。

## Data Design Rules

- Every question must be original.
- Every question must include a clear Chinese explanation.
- Each level has vocabulary, grammar lessons, practice questions, and at least five mock exams.
- Mock exams are training simulations, not official papers.
- Question banks should mix confidence, on-level, and stretch items, but avoid幼儿英语风格.
