# Content Quality Rules

V3 data is local JSON and must be checked before release.

## Vocabulary

- Every word must have `word`, `phonetic`, Chinese meaning, Japanese meaning, part of speech, and example sentence.
- Example sentence must have Chinese and Japanese translations.
- Avoid幼儿化词汇 for Grade 4. Use Japanese junior-high appropriate words.
- Pre-2 vocabulary should include school, environment, technology, health, community, and opinion topics.

## Grammar

- Every grammar lesson must have Chinese explanation, Japanese explanation, structure, examples, common mistakes, and mini quiz.
- Each mini quiz must have choices, answer, and Chinese explanation.
- The answer must appear in choices.

## Questions

- Every question must have exactly 4 choices.
- `answer` must be one of `choices`.
- Every question must have Chinese explanation.
- Reading questions must include a non-empty passage.
- Duplicate question text within the same level is not allowed.

## Mock Exams

- Each level must have at least 5 mock exams.
- Grade 4 does not require writing.
- Grade 3 and Pre-2 must include writing tasks.
- Writing tasks must include a sample answer or scoring points.
- Each exam must include an answer key for multiple-choice questions.
